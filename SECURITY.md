# Security policy

Please report vulnerabilities privately through GitHub's "Report a vulnerability" button under
the repository's **Security** tab (private vulnerability reporting). Do not open a public issue.

Relevant concerns include: leaking environment values or file contents, executing project
content, following symlinks outside the inspected directory, and output that could inject
instructions into an AI agent consuming the JSON.

This project is maintained on a best-effort basis; no response-time guarantee is made.
